# EVIL HANGMAN TERMINAL GAME

AUTHOR: Maria

DESCRIPTION:
A terminal EvilHangman game. 
Depending on the difficulty the user chooses, the first 1–3 guesses are always wrong, because the computer picks the word only after them. 
Then the user tries to guess the 9-letter word in no more than 10 wrong guesses in total.
After the game has finished, the user can choose to quit or play again.

PURPOSE: 
It is an entertaining app the purpose of which was to improve my skills on working with git and projects with several files.
